1 INTRODUCTION

## 1.1 GENERAL INFORMATION

The Interactive Fatigue program allows for reviewing of tubular connection fatigue results and redesigning connections in a 3D interactive environment. The program requires a fatigue extract file generated by the Fatigue batch program module as input. Various reports and plots of fatigue results can be generated and saved.

1.1.1 Program Features

Some of the main features of the Interactive Fatigue program are:

1. Shows the 3-D view of the connection and allows for braces to be selected with the mouse.   
2. Allows for redesigning of chord and brace members based on fatigue results.   
3. Allows SCF theory to be changed for any type connection, including in-line connections and connections with user defined SCFs.   
4. Provides the ability to designate the S-N curve used to determine allowable cycles.   
5. Recognizes all SCF and S-N options available in the batch program.   
6. Full reporting capabilities.   
7. Full plotting capabilities, including transfer function, response function, wave spectrum, stress range versus cycles and various other plots.   
8. Reports and plots can be displayed on the screen or saved to a file.

## 1.2 PROGRAM OVERVIEW

1.2.1 File Naming Conventions

While no file naming convention is required for Interactive Fatigue, the file name filter is used in the Open dialog box depending on the naming convention set in SACS Executive. The default filter is ???ext.* for the naming convention pgmtyp.ver and *.ext for verpgm.typ. Plot filenames may be specified by the user using Save NPF As under the File menu, and reports may be saved from the SACS report viewer program which is automatically called when reports are requested from the Reports menu.

2 GETTING STARTED

## 2.1 BEGINNING AN INTERACTIVE FATIGUE SESSION

To start the Interactive Fatigue program, type "ifatigue filename" where filename is the Fatigue extract file name. Interactive Fatigue can also be launched from the SACS Executive by selecting Interactive Fatigue from the menu then selecting an extract file name.

If an extract file name is not selected, the program is initiated with a blank screen. An extract file can then be selected using the File/Open menu selection.

When a Fatigue extract file is opened, Interactive Fatigue initially displays the first joint of the file with the first brace listed shown as the selected brace. Different joints may be selected using the Joints/Select menu option. Braces may be selected using the Members/Select Brace menu option or by simply clicking on the desired brace with the mouse.

Various display features, such as fill, double line drawing, labeling, and rotate are available in the Display Menu.

![](SACS2024_Legacy_Interactive_Fatigue/22b5a330d195b42ccf94fb32672acac1ba3ce559154686e441e6dcf104d39af5.jpg)

## 2.2 FATIGUE CONNECTION COORDINATE SYSTEM

For each SACS load case making up the fatigue environment, fatigue results are evaluated at eight points spaced at 45 degrees around the perimeter of the welded connection on both the chord and brace side, see Figure 1 below:

![](SACS2024_Legacy_Interactive_Fatigue/e758fb7faa8b68ff06030750be787ec9fee2bf5d24f8ecce1991e4ea7ce554e9.jpg)  
Figure 1

Note: The top of the connection is at the intersection of the brace/chord plane opposite of the chord reference joint. The Bottom position is therefore always at the intersection of thebrace/chord plane on the side nearest to the chord reference joint.

## 2.3 EXISTING THE INTERACTIVE FATIGUE SESSION

Select the File/Exit menu option to exit the Interactive Fatigue session. If any plots or reports that have been generated to a file have not been saved, the user is prompted whether or not to save the file.

## 8.4 STRESS VS. CYCLES

The Stress vs. Cycles command creates a bar graph showing stress range and number of cycles plotted against the S-N allowable curve. The chord or brace position along with the applicable fatigue load case must be designated on the Plot Options dialog.

The Stress vs. Cycles plot is generated as follows:

For a point on the connection, the maximum cyclic stress is found considering all spectra for the direction in question. This maximum stress is then broken into 20 cyclic stress bands or categories. For each band, the total damage and number of cycles is summed. The report and plot shows the range and cycles for a band only if the band causes actual damage.

![](SACS2024_Legacy_Interactive_Fatigue/41a8eb8d0a451ff6987a33409861eef1d2f27ab501013469d40751df4019ecf6.jpg)

12 Damage accumulation MENU FEATURES

This menu is only applicable when using a fatigue extract summation file. This file is auto generated by adding the extract line to the partial fatigue input file used in sacs wind turbine and GHBladed processes. Refer to Wind Turbine manual section 2 and 3 for details. User can create this file manually to sum up damages from different fatigue runs. It should be noted that in order to use this option all joint should be extracted by entering ‘AL’ in columns 14-15 of EXTRACT HEAD line.

The Fatigue Extract summation files as shown below contains the following information:



| SUMFTGIFT: Flag indicating a summation extract file |
| --- |
| NCASES: Defines the number of simulation for analysis cases. |
| NGRPS: Defines the number of groups for analysis cases. |
| DIRECTORY: Directory location for fatigue extract file for a fatigue simulation |
| EXTRACT: Name of the extract file generated from above run |
| GROUP: Defines the group above run belongs to |
| Repeat the above (Directory to Group) for other simulations (total equals NCASES) |
| JOINTS: Defines the number of joints to be viewed in interactive fatigue (since not all joints need to be viewed) |
| Repeat all joint ID's desired (total equals JOINTS). |



The example below shows a typical fatigue extract summation file for three simulations with 497 joints chosen to view.

```csv
SUMFTGIFT  
NCASES,3  
NGRPS,2  
DIRECTORY,"D:\Bentley\000Sample\1"  
EXTRACT,"ftgext.dat"  
GROUP,1  
DIRECTORY,"D:\Bentley\000Sample\2"  
EXTRACT,"ftgext.dat"  
GROUP,2  
DIRECTORY,"D:\Bentley\000Sample\3"  
EXTRACT,"ftgext.dat"  
GROUP,2  
JOINTS,497  
1  
3  
5  
7  
24  
71  
73  
75  
77 
```
