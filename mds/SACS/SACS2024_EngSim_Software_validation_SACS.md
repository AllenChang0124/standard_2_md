SACS is a sophisticated design and analysis application for Offshore Structural engineering practitioners to assess the safety and compliance of their designs. SACS has been validated by both manual and automated testing procedures as part of a comprehensive product test plan consisting of more than 500 verification and validation test cases. Software quality metrics are defined against a quality standard established by existing and historical commercial versions of the program. Results from the program are compared with a variety of published and/or hand calculations and with automated tools for validity and accuracy.

Technical support for this analysis product is provided by a dedicated team with both product and domain knowledge. The level of support is described in Bentley SELECT Program Agreement and includes free software upgrades and updates as they become available, in line with the Bentley Lifecycle Policy.

At Bentley Systems we are committed to protecting the personal data of our users. We employ effective application security controls with respect to the level of risk for each application. The development of this desktop application has ensured that effective security controls are in place. Some of the security controls and checks performed before a release of the product are listed below:

Static analysis of source code   
Known security issues and vulnerabilities scan   
Existence of a (internal) product security site   
Named product security champion   
Security champion up to date on training

We certify that this version of our software has passed all applicable security checks in place according to Bentley Systems' security controls in place at the time of release.
