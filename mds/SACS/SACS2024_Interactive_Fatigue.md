1 INTRODUCTION

## 1.1 GENERAL INFORMATION

The Interactive Fatigue program allows for reviewing of tubular connection fatigue results and redesigning connections in a 3D interactive environment. The program requires a fatigue extract file generated by the Fatigue batch program module as input. Various reports and plots of fatigue results can be generated and saved.

1.1.1 Program Features

Some of the main features of the Interactive Fatigue program are:

1. Shows the 3-D view of the connection and allows for braces to be selected with the mouse.   
2. Allows for redesigning of chord and brace members based on fatigue results.   
3. Allows SCF theory to be changed for any type connection, including in-line connections and connections with user defined SCFs.   
4. Provides the ability to designate the S-N curve used to determine allowable cycles.   
5. Recognizes all SCF and S-N options available in the batch program.   
6. Full reporting capabilities.   
7. Full plotting capabilities, including transfer function, response function, wave spectrum, stress range versus cycles and various other plots.   
8. Reports and plots can be displayed on the screen or saved to a file.

## 1.2 PROGRAM OVERVIEW

1.2.1 File Naming Conventions

While no file naming convention is required for Interactive Fatigue, the file name filter is used in the Open dialog box depending on the naming convention set in SACS Executive. The default filter is ???ext.* for the naming convention pgmtyp.ver and *.ext for verpgm.typ. Plot filenames may be specified by the user using Save As under the File menu, and reports may be saved from the SACS report viewer program which is automatically called when reports are requested from the Reports menu.

## 5.2 PROPERTIES

Onscreen textural data is divided over three dockable windows. The default arrangement is for the Fatigue Summary tree view to be on the left and the Fatigue Input and Fatigue Results panels to be stacked in a tabbed window on the right.

These windows are opened when a fatigue extract is first loaded. If they become closed, they can be reopened with the Properties command.

![](SACS2024_Interactive_Fatigue/0f2b4fa94f8d5ac078a36b69ec7a4ee39c52af3a831e51b6ec48dab3523dcad4.jpg)

5.2.1 Fatigue Summary Tree

This panel shows a summary of the joints and members which are contained in the fatigue extract file.

![](SACS2024_Interactive_Fatigue/9a9efd86cab61fe6727048df12e6f431951e038ad60a8ba38f5e35b447a06bfa.jpg)

Each item is colored accorded to the current Damage:Color bands used by the graphical display. A higher level item is colored according to the worse case child item.

The two icons at the top of the view sort the joints by file read order (left) or by max damage (right). Braces, or member transition points are always under, and sorted within, their appropriate joint or member.

Selecting an item in this panel will cause the same item to be selected in the graphical view, and in the fatigue input & results panels. A selection of a joint will cause the chord element(s) to be drawn selected, but not the individual braces.

Joint, brace and transition point items in the tree support pop up menus. These are accessed with a mouse right-click.

![](SACS2024_Interactive_Fatigue/53de25f79239b4c9b51713a45d053144fc24cc7aa10b9b4df3b9f242f0f4fbd2.jpg)

The menu options are dependent on the level of the item being selected. Show Joint will create a new graphical view with only the selected joint visible. Report & Plot allow access to reports and charts for the selected item. Reset Joint will discard any changes made to the Joint’s design parameters during this session.

5.2.2 Fatigue Input Panel

This panel has a variety of forms dependent on the most recently selected fatigue item, either from the Summary tree panel or from the graphical display.

These property panels may be edited. When editing data, all relevant redesign is performed and the summary tree, graphical display and result panel are updated. Data which has changed by the user is shown in bold.

If the Joints or Members tree panel item is selected, the panel will show the general fatigue design parameters. Data here affects all joints and members which do not have specific overrides.

The icon at the top of the panel will reset the data to that first read from fatigue extract file.

![](SACS2024_Interactive_Fatigue/7e32d5552cbbec4cf68886dfb6f8e159304f5daaeca79da04fb79c9269b799fa.jpg)

If a joint is selected in the fatigue summary tree or a chord selected in the graphical display, the input panel will show the design parameters relevant to that joint’s design.

![](SACS2024_Interactive_Fatigue/9f34b221cfeaa42d7fef4b2f0a25de4b86db23ef639a25dd688a0805bdf48297.jpg)

Chord properties will affect the design of all brace elements at this joint. Data items with a text entry will indicate that they are inherited from the general options with the suffix (No Override).

If a brace is selected in the fatigue summary tree or in the graphical display, the input panel will show the design parameters relevant to that brace’s design.

![](SACS2024_Interactive_Fatigue/4c14d818468abd4497790da6917511db1b5b3471c63ab921750549f167eb3af1.jpg)

This follows the principals above. Changing the chord properties will alter that chord element’s properties when other braces at that joint are redesigned. If using the LDPATH option the connection type will not be editable.

There are similar input property panels for inline joint design and for member transition point design.

5.2.3 Fatigue Result Panel

When the selection in the summary tree is a joint or if the graphical selection is a chord element, this will show summary result information for the joint.

If a joint is selected in the fatigue summary tree or a chord selected in the graphical display, the input panel will show the design parameters relevant to that joint’s design.

![](SACS2024_Interactive_Fatigue/6792791b7e4aac156ec48951e067f3c2ddf3e218d25c7094e08d4131afddae2a.jpg)

When the selection in the summary tree is a brace or if the graphical selection is a brace element, this will show result information for the joint.

When the selection in the summary tree is a joint or if the graphical selection is a chord element, this will show summary result information for the joint.

![](SACS2024_Interactive_Fatigue/28d41aa4ce3069240d31800e28cb1fe3ba4dc761a1077a144f10422500346055.jpg)

There are similar result property panels for inline joint design and for member transition point design.

5.3.4 FATIGUE STRESS V. CYCLES

The Stress vs. Cycles command creates a bar graph showing stress range and number of cycles plotted against the S-N allowable curve. The chord or brace position along with the applicable fatigue load case must be designated on the Plot Options dialog.

The Stress vs. Cycles plot is generated as follows:

For a point on the connection, the maximum cyclic stress is found considering all spectra for the direction in question. This maximum stress is then broken into a number of cyclic stress bands or categories. For each band, the total damage and number of cycles is summed. The report and plot shows the range and cycles for a band only if the band causes actual damage .

![](SACS2024_Interactive_Fatigue/f634510975b866ba5f7fd4571a3856ac848c2b77af2ec465dcd2438227917362.jpg)

## 5.7 DAMAGE ACC. (Accumulation)

This menu is only applicable when using a fatigue extract summation file. This file is auto generated by adding the extract line to the partial fatigue input file used in sacs wind turbine and GHBladed processes. Refer to Wind Turbine manual section 2 and 3 for details. User can create this file manually to sum up damages from different fatigue runs. It should be noted that in order to use this option all joint should be extracted by entering ‘AL’ in columns 14-15 of EXTRACT HEAD line.

The Fatigue Extract summation files as shown below contains the following information:

SUMFTGIFT: Flag indicating a summation extract file

NCASES: Defines the number of simulation for analysis cases.

NGRPS: Defines the number of groups for analysis cases.

DIRECTORY: Directory location for fatigue extract file for a fatigue simulation

EXTRCT: Name of the extract file generated from above run

GROUP: Defines the group above run belongs to

Repeat the above (Directory to Group) for other simulations (total equals NCASES)

JOINTS: Defines the number of joints to be viewed in interactive fatigue (since not all joints need to be viewed)

Repeat all joint ID’s desired (total equals JOINTS).

The example below shows a typical fatigue extract summation file for three simulations with 497 joints chosen to view.

```csv
SUMFTGIFT  
NCASES,3  
NGRPS,2  
DIRECTORY,"D:\Bentley\000Sample\1"  
EXTRACT,"ftgext.dat"  
GROUP,1  
DIRECTORY,"D:\Bentley\000Sample\2"  
EXTRACT,"ftgext.dat"  
GROUP,2  
DIRECTORY,"D:\Bentley\000Sample\3"  
EXTRACT,"ftgext.dat"  
GROUP,2  
JOINTS,497  
1  
3  
5  
7  
24  
71  
73  
75  
77 
```

An extract summation file may be imported into Precede in the same manner as a normal fatigue extract file.

The initial state is to have all referenced simulations loaded. The shown results are the summation across all referenced extract files.
